# プロダクト開発（売れるものにするための作業）

このディレクトリは、`shiba-run` を「動くコード」から「売れるプロダクト」にするための作業場です。
`plans/` が**技術的な実行計画**を置く場所なのに対し、ここは**何を誰に売るかの判断**を置く場所です。

## この文書の使い方（セッションをまたぐ人・AIへ）

文脈を持たない状態でここに来たら、次の順で読めば追いつけます。

1. この README の「現在地」
2. `decisions.md`（何を決めて、何を却下したか）
3. 必要な調査だけ `research/` から拾う（**全部読まないこと**。各文書の冒頭3〜5行に結論がある）

調査の生データは `research/` に隔離してあります。判断だけを上位の文書に引き上げ、
根拠が要るときだけ下に降りる、という構造です。

## フェーズの定義とゲート

商業開発のフローは工程表ではなく**中止判断の連鎖**です。安い工程を先に置き、
高い工程に進む前に必ずゲート（続行／作り直し／中止）を通します。

| # | フェーズ | 目的 | 成果物 | ゲート（通過条件） |
|---|---|---|---|---|
| 0 | 発案・市場調査 | 誰に何を売るかを決める | ワンシート | 1文で説明でき、買う人が想像できる |
| 1 | プロトタイプ | 面白いかだけを確かめる | 遊べる検証台＋結果 | 他人が説明なしで遊び、2回目を始める |
| 2 | プリプロダクション | 量産の設計図を確定 | 完成品質の1面／露出開始 | 残りの作業量と期日が言える |
| 3 | プロダクション | 量産 | 全コンテンツ | 最初から最後まで通せる |
| 4 | 仕上げ | 出せる状態にする | 審査通過ビルド | 外部の人が詰まらず終われる |
| 5 | ローンチ | 出す | 公開 | — |
| 6 | 運用 | 数字を見て直す | 更新 | — |

**このプロジェクトの原則: 初回作なので、最小の規模で 0→5 を一周する。**
規模で勝負しない。「出し切る経験」と「1つの尖った点」を取りに行く。

### 技術資産の棚卸し（2026-08-13 時点）

| 項目 | 状態 |
|---|---|
| 実装 | 素のJS + Canvas、外部依存ゼロ、約1000行、17モジュール |
| 画面 | 640×480、タイル40px、12行 |
| 面 | 2面（1面は260列 ≒ 10,400px）。データ駆動で追加が容易 |
| 敵・ギミック | 5種（猫・カラス・砲台・バネ・移動床）＋ボス。登録制で追加が容易 |
| プレイヤー動作 | 移動・2段ジャンプ・ショット・チャージショット・踏みつけコンボ |
| 進行 | HP6／残機3、骨（スコア）、肉（無敵）、中間地点4、ボス戦、タイムボーナス |
| 周辺 | セーブ（localStorage）、面セレクト、ポーズ、ミュート、タッチ操作 |
| 品質保証 | 描画列ハッシュによるリプレイ検証4シナリオ＋CI |
| 音 | Web Audio による合成音（音声ファイルなし） |
| 素材 | 画像アセットなし（すべてコード描画の図形） |

見た目の実物は `research/shots/`（`title.png` / `play.png`）。実ブラウザで撮ったもの。

**強み**
- 依存ゼロ。ブラウザさえあればどこにでも置ける。配信先を選べる立場にある
- 見た目が figures とは思えない水準にまとまっている。フラットで淡い配色、丸みのある柴犬、
  余白の取り方が今風で、「素人が作った感じ」がしない。ここは想定より強い資産
- リプレイ検証があるので、壊したらすぐ分かる。触り続けられる
- 面・敵をデータで足せるので、コンテンツ追加が安い

**弱み**
- 企画上の差別化がゼロ。「柴犬が走る2Dアクション」は現状それ以上の何物でもない
- 1プレイの体験が未検証。**素人操作で開始5秒のうちにHPが6→2まで減った**（実測）。
  初見の難易度が高い可能性がある。カジュアル層に出すなら致命的になりうる
- 画像・音の素材がゼロ。長所（軽い）と短所（印象に残りにくい）の両面
- 遊ぶ動機が「クリアする」しかない。もう一度遊ぶ理由がまだ設計されていない

## 進め方の原則

- 調査や大量読解は**サブエージェントに投げ、成果はmdに書かせる**。会話に生データを持ち込まない
- 判断は必ず `decisions.md` に、却下案とその理由まで残す
- 数字には出典を付ける。出典のない数字は書かない。推測は「推測」と明記する
- コードを触るときは `CLAUDE.md` の検証ルール（`tools/replay-check.mjs`）に従う
